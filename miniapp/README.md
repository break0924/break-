# 好友德州局 - 微信小程序版

## 目录

- `app.js` / `app.json` / `app.wxss`
- `pages/index/index.*`
- `utils/api.js`

## 使用

1. 用微信开发者工具打开 `miniapp/` 目录
2. 将 `app.js` 里的 `apiBase` 改成你的后端地址，或在首页直接保存地址
3. 真机测试时，不要用 `127.0.0.1`，改成电脑局域网 IP，例如：`http://192.168.0.106:8787`
4. 确保后端服务运行在对应地址
5. 创建房间或通过分享链接进房

## 真机测试步骤

1. 电脑和手机连同一个 Wi-Fi
2. 启动后端：`HOST=0.0.0.0 PORT=8787 python3 server.py`
3. 在电脑上确认局域网地址，比如 `http://192.168.0.106:8787`
4. 在小程序首页填写这个服务器地址并点击保存
5. 微信里预览或真机调试打开页面

## 注意

- 微信小程序开发者工具里，真机调试通常需要开启“不校验合法域名”等开发选项
- 如果你后面要正式上线，需要把后端放到 **HTTPS 公网域名** 下
- 目前这个版本是适合内测和朋友局的开发版

## 当前能力

- 创建房间
- 加入房间
- 开局、过牌、跟注、加注、弃牌
- 基于后端轮询同步状态
- 分享房间链接
