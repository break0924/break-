# 微信小程序上线前检查清单

## 小程序基础信息

- 小程序名称与页面内容一致，建议体现“AI 足球分析”“世界杯数据”等内容属性。
- 类目选择匹配内容资讯、体育资讯或工具类能力，以平台审核结果为准。
- 图标、简介、截图不暗示确定性结果或收益。
- 分享标题和分享图只表达内容分析、赛事讨论和挑战积分。

## 协议与隐私

- 已配置隐私协议。
- 已配置用户协议。
- 已说明收集的用户信息范围：OpenID、昵称、头像、会员状态、预测记录、支付订单状态。
- 已说明数据用途：登录识别、会员权益、内容展示、积分计算和客服排查。
- 已提供账号信息处理和客服联系方式。

## 服务器与域名

- 后端 API 使用 HTTPS。
- 微信公众平台已配置 request 合法域名。
- 支付回调地址可公网访问。
- 生产环境关闭调试日志中的密钥信息。
- `JWT_SECRET` 已替换为高强度随机值。

## 支付配置

- 已配置小程序 AppID。
- 已配置商户号。
- 已配置证书序列号。
- 已配置 API v3 Key。
- 已挂载商户私钥文件。
- 已配置平台公钥。
- 支付说明明确为会员内容服务。
- 支付成功后只开通会员内容权益。

## 内容合规

- 首页底部展示合规声明。
- 会员页展示权益边界。
- AI 分析页展示风险提示。
- 挑战赛页面展示积分规则和锁定规则。
- 所有 AI 生成内容经过敏感内容过滤和风险提示补齐。
- 不展示资金账户、交易撮合、票据处理、收益返还或推广收益相关能力。
- 不使用确定性结果承诺类表达。

## 会员说明

- 会员名称、价格、有效期清晰。
- 会员权益只包含完整 AI 报告、每日精选完整理由、历史命中率和高级榜单。
- 会员权益不包含现金权益、结果承诺或线下履约。
- 支付失败、取消支付、订单处理中均有明确提示。

## 风险提示

- AI 内容仅为足球数据分析参考。
- 比赛结果受临场阵容、伤停、天气、裁判判罚、战术调整等因素影响。
- 挑战赛为娱乐积分活动，积分、称号和榜单仅用于站内展示。
