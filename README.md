# 德州扑克好友局 MVP

一个可本地运行、可手机扫码、可部署到公网的德州扑克娱乐项目。

## 功能

- 创建房间
- 好友扫码 / 输入房间号加入
- 服务端同步牌局状态
- 基础德州扑克动作：过牌、跟注、加注、弃牌
- 结算、庄家轮换、牌桌 UI、二维码分享
- 微信小程序版页面骨架

## 本地启动

```bash
python3 server.py
```

打开：`http://127.0.0.1:8787`

## 手机访问

同一 Wi-Fi 下，用电脑局域网 IP 打开，例如：

```text
http://192.168.0.106:8787
```

- `miniapp/`：微信小程序前端
